Github repository for Breakthrough, a 2D platform fighter by Brayden Stuchell and Ben Raduns made with the Unity Engine.

The game features four playable characters with unique movesets, and functions similar to a typical platform fighter. The main difference
is that many of the walls of each arena are breakable, and you must send your opponent flying into them to break them before anyone can
be KO'd.
